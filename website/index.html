vinny

A tiny VNC server for your Mac

Terminal
$ vinny serve
● listening on 127.0.0.1:5900
View on GitHub

CLI options

vinny serve [options]
--listen <ip>
Loopback or Tailscale address 127.0.0.1
--port <port>
VNC port from 1 to 65535 5900
--display <index>
Display to capture 0
--max-width <pixels>
Downscale wider displays 1920
--fps <fps>
Capture rate from 1 to 60 20
--no-request
Check permissions without prompting
--parent-stdio
Stop when the parent process closes stdin
