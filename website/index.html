Why use Vinny instead of built-in Screen Sharing?

Start with Apple's built-in option for ordinary Mac screen sharing. Choose Vinny when you want visible, per-server controls for displays, capture settings, ports, and viewer policies, or want to inspect and modify the source.

Get your first connection working

  1. Install and open Vinny

    Use Homebrew above, or unzip the download and move Vinny.app to Applications. The published download is for Apple silicon Macs.

  2. Grant permissions

    Allow Screen Recording and Accessibility when prompted. Both permissions are required before enabled servers start.

  3. Start a local listener

    Choose your display, keep 127.0.0.1:5900, and enable the server. That address deliberately accepts connections only from this Mac.

  4. Connect through SSH

    Follow the TigerVNC guide to forward a port from your other computer. SSH protects the connection while Vinny stays on loopback.

Before you connect

Does Vinny work outside my home network?

Vinny does not provide a cloud relay or automatic access through your router. Use a secure tunnel to a Mac you can already reach. The first connection guide assumes working SSH access.

Why does connecting to my Mac's IP address fail?

The default listener binds to 127.0.0.1, so it is available only on the Mac itself. Keep that setting and use the SSH connection guide.

Can I connect with Apple's Screen Sharing app?

Vinny supports optional legacy VNC authentication for that client. Legacy authentication does not encrypt the session, so use a secure tunnel. The first connection guide uses TigerVNC.

Does view-only mode hide sensitive content?

No. It blocks remote input and incoming clipboard changes, but viewers still see everything shown on the selected display. Clear sensitive windows and notifications before sharing.

Where should I report a connection problem?

Open a GitHub issue with your macOS version, viewer and version, server settings, and the exact error. Leave out passwords, private hostnames, and screen contents.
