Share a selected Mac display over VNC

Vinny configures capture per server. Give a listener one display, its own port, and its own capture and viewer settings. This guide assumes you have completed the first connection setup.

Choose the screen

  1. Open Vinny and find the server you want to configure.
  2. Select the monitor in Display. Check its label before connecting a viewer.
  3. Set Maximum width and Frame rate. Start with 1920 and 20 FPS, then adjust for your network and what you are sharing. These are starting settings, not performance guarantees.
  4. Choose Apply & restart. Reconnect the viewer if the restart closes your session.

Maximum width controls captured output, not the Mac's physical display resolution. A display selection is not an application-only sharing filter. Viewers can see anything that appears on that monitor, including notifications.

Make it view-only

Turn off Allow keyboard and mouse under Remote control, then apply the change. This blocks remote keyboard, pointer, and incoming clipboard changes. Viewers still receive screen and outgoing clipboard contents. This setting does not encrypt the connection.

Share another monitor separately

Use Add server, select the other display, and choose an unused port. New configurations look for the next available configured port starting at 5900. Keep the new listener on 127.0.0.1 when using SSH. Enable it and choose Apply & restart.

For example, if the second listener uses port 5901, forward it separately:

ssh -N -o ExitOnForwardFailure=yes \
  -L 127.0.0.1:15901:127.0.0.1:5901 \
  your-mac-user@mac-host

In TigerVNC, connect to 127.0.0.1::15901. Replace the account and host as described in the SSH guide.

Choose how viewers share a session

  • Viewer decides: a viewer can share the session or request exclusive access.
  • Allow multiple viewers: new viewers can join without disconnecting an existing viewer.
  • One viewer at a time: new connections are rejected while a viewer is connected.

These controls are per listener. They do not create separate macOS user sessions. Check the selected display after connecting, and again if you reconnect or rearrange monitors.
