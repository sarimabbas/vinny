Connecting with TigerVNC

Keep Vinny on its default loopback address and forward a port over SSH from your viewing computer. You need Vinny on the Mac being shared, TigerVNC Viewer and an SSH client on the other computer, and working SSH access to the Mac.

This recipe uses SSH for encryption and authentication. Vinny's default VNC listener itself has neither. Keep it bound to 127.0.0.1. Use trusted computers: other local users or processes may be able to reach the listener or the forwarded port.

1. Prepare the Mac being shared

  1. Install Vinny, open it, and grant Screen Recording and Accessibility. Both permissions are required before enabled servers start.
  2. Choose a display. Keep Listen on at 127.0.0.1 and port 5900. For this SSH recipe, leave Encrypted + password off. Enable the server and confirm it is listening.
  3. Enable Remote Login in macOS Sharing settings, allowing only the account you intend to use. The settings location varies by macOS version. Use Apple's Remote Login instructions. Note the SSH command displayed there.

2. Open the tunnel on the viewing computer

Replace your-mac-user and mac-host with the account and address from Remote Login. The Mac must already be reachable from this computer.

ssh -N -o ExitOnForwardFailure=yes \
  -L 127.0.0.1:15900:127.0.0.1:5900 \
  your-mac-user@mac-host

Verify the SSH host key through a trusted channel before accepting a first connection. Sign in using your configured SSH authentication. Leave this terminal running. A successful tunnel usually produces no further output.

3. Connect TigerVNC Viewer

Enter this in TigerVNC's server field:

127.0.0.1::15900

The double colon tells TigerVNC to use the explicit TCP port. Connect to this local forwarded address, not the Mac's network address. The underlying VNC connection is unauthenticated, but traffic between the computers travels through SSH. If your viewer disables unauthenticated VNC, allow its None security type only for this loopback tunnel.

You should see the selected display. To try remote control, move a non-sensitive window or type in a blank document. Disable Allow keyboard and mouse in Vinny and apply the settings to try view-only mode.

If the connection fails

  • SSH connection refused or timed out: check Remote Login, the hostname, your network route, and whether the Mac is awake. A tunnel cannot reach a Mac that SSH cannot reach.
  • Local port already in use: change 15900 in both the SSH command and viewer address.
  • Tunnel opens but VNC fails: confirm Vinny is listening on 127.0.0.1:5900. If another service uses port 5900, pick another Vinny port and change the final :5900 in the tunnel command to match.
  • Server will not start: check both macOS permissions and the error shown in Vinny.
  • Picture works but input does not: check Accessibility access and Allow keyboard and mouse.

Finish the session

Close the viewer and press Ctrl+C in the SSH terminal. Disable the Vinny server if you no longer need it. If you enabled Remote Login only for this session, turn it off again.
